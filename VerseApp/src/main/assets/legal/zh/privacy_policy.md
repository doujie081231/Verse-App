# Verse App 隐私政策

生效日期：2026 年 11 月 1 日
适用版本：Verse App（Android）1.3.4 及以后版本

## 一、引言

本政策说明 Verse App（以下简称「本应用」）如何处理你的信息。核心原则只有一条：**能留在你设备上的数据，就不上传**。

本应用是本地启动器，没有自主运营的账号体系与云存档服务。

## 二、保存在你设备上的信息

以下数据仅保存在应用私有目录或游戏目录，不会自动上传：

- **设置**：内存分配、渲染器、Java 版本、下载源、界面偏好；
- **账户**：账户类型、用户名、UUID、登录令牌（用于启动游戏）；
- **版本与游戏文件**：游戏版本清单、库文件、存档、模组、资源包、光影；
- **日志**：启动过程、安装过程、下载记录，用于本地排查问题。

卸载应用或在系统设置中清除应用数据会删除上述内容，请在操作前自行备份存档。

## 三、联网时涉及的信息传输

以下传输仅在你使用对应功能时发生：

### 3.1 Minecraft 账号认证

使用正版账户登录时，认证由 Microsoft 官方服务完成，直接与你设备上的微软登录页交互，本应用不获取你的密码。

### 3.2 第三方认证服务器（外置登录）

当你填写并连接第三方皮肤站时，认证请求（用户名、密码或设备码、令牌）直接发送至**你填写的服务器**。该服务器由第三方运营，其信息处理方式适用该服务器的隐私政策。

快捷登录使用设备码流程：本应用向该服务器申请设备码并在浏览器中完成授权，本应用不接触你在该网站的密码。

### 3.3 游戏与资源下载

下载游戏文件、模组、整合包时，本应用会向相应服务器发送常规 HTTP 请求（包含你请求的文件路径与客户端标识）。涉及的服务器可能包括：

- Minecraft 官方资源服务器与版本清单服务；
- 公开镜像站（如 BMCLAPI）；
- Modrinth、CurseForge 等内容平台及其镜像。

这些服务可能按其自身政策记录访问日志（如 IP 地址）。

### 3.4 更新检查

应用启动与手动检查更新时，会向项目更新接口请求版本信息，请求内容不包含你的个人信息。

### 3.5 问题反馈

只有当你主动提交反馈时，本应用才会将你填写的问题描述、设备与版本信息（系统版本、机型号、Java 版本、启动器版本）以及你选择附带的日志文件上传至反馈服务。

反馈内容仅用于定位与修复问题。若你不希望提供日志，可以不勾选附件或不上传日志文件。

### 3.6 赞助与外部链接

「前往赞助」「项目主页」等按钮会在系统浏览器中打开第三方网页（如爱发电、GitHub）。你在这些网站上的操作适用该网站的隐私政策，本应用无法读取你在其中的数据。

「关于 → 致谢」与每月的赞助者感谢弹窗会展示当月赞助者在爱发电的**公开昵称与赞助金额**。该名单由开发者从爱发电后台导出后随应用版本发布，不包含头像、订单号、联系方式或其它未公开信息。若你不希望昵称出现在名单中，可通过问题反馈告知，我们会在下个版本移除。

## 四、本应用不收集的信息

- 不收集你的通讯录、短信、通话记录；
- 不收集你的地理位置；
- 不读取与游戏无关的个人文件；
- 不内置第三方广告 SDK 或行为分析 SDK；
- 不将你的账户令牌上传到开发者服务器。

## 五、权限说明

| 权限 | 用途 |
|---|---|
| 网络 / 网络状态 | 下载游戏与资源、检查更新、提交反馈 |
| 通知 | 显示下载进度与新版本提醒 |
| 前台服务（如使用） | 保证后台下载不中断 |
| 存储（按系统版本） | 读取与写入游戏目录、导入整合包 |

## 六、儿童

本应用不面向 14 周岁以下儿童单独提供服务。未成年人应在监护人指导下使用。

## 七、政策变更

政策发生实质性变化时，本应用会在启动时重新展示并要求你确认。历史版本可向反馈渠道索取。

## 八、联系我们

如对本政策有疑问，可通过应用内「问题反馈」提交，或通过项目主页联系开发者。
